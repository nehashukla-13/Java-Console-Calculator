# Java-Console-Calculator
Java Console Calculator - Java Developer Internship Task 1

## Objective

Build a basic calculator using Java console input and output.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User input using Scanner
- Multiple calculations using a loop
- Divide-by-zero handling
- Exit option

## Technologies Used

- Java
- Scanner
- Methods
- Conditional statements
- Switch statement
- While loop

## How It Works

The program displays a menu with different arithmetic operations. The user selects an operation and enters two numbers. The calculator performs the selected operation and displays the result.

The calculator continues running until the user selects the Exit option.

- Java syntax and logic flow
- Methods
- Console I/O
- Loops
- Conditionals
- Basic OOP concepts
